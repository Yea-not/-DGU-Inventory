# ДГУ Инвентарь

Учебная система учёта оборудования, QR-инвентаризации и обработки заявок.

## Возможности

- Реестр оборудования: добавление, редактирование, поиск и карточки устройств.
- Учёт корпусов, этажей и кабинетов.
- QR-коды для открытия карточек оборудования.
- Создание и обработка заявок, статусы, комментарии и история изменений.
- Инвентаризация с отметкой проверки.
- Роли администратора и сотрудника, управление пользователями.
- Статистика и демонстрационный ИИ-помощник.

## Что установить

- Python 3.10 или новее.
- Node.js LTS (в комплекте npm).
- Любой современный браузер.

Проверка установки:

```bash
python --version
node --version
npm --version
```

На macOS/Linux используйте `python3`, если команда `python` недоступна.

## Запуск на Windows

Распакуйте архив. Откройте PowerShell в корневой папке проекта.

**Терминал 1 — backend:**

```powershell
cd backend
py -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Если PowerShell запрещает активацию окружения, используйте CMD и команду `venv\Scripts\activate.bat`.

**Терминал 2 — frontend:** откройте второе окно PowerShell в корневой папке проекта и выполните:

```powershell
cd frontend
npm install
npm run dev
```

## Запуск на macOS и Linux

Распакуйте архив и откройте Terminal в корневой папке проекта.

**Терминал 1 — backend:**

```bash
cd backend
python3 -m venv venv
source venv/bin/activate
python3 -m pip install -r requirements.txt
python3 -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

**Терминал 2 — frontend:** откройте новое окно Terminal в корневой папке проекта и выполните:

```bash
cd frontend
npm install
npm run dev
```

## Открытие приложения

Откройте в браузере `http://localhost:5173`. Документация API доступна по адресу `http://localhost:8000/docs`, пока backend запущен. Backend и frontend должны работать одновременно в двух окнах терминала.

## Демо-вход

> Важно: это демонстрационные учётные данные для локального запуска. Не используйте их для публичного развёртывания.

- **Логин:** `admin`
- **Пароль:** `admin123`

При первом запуске backend автоматически создаёт базу `backend/inventory.db`, демонстрационную учётную запись и начальные записи оборудования. Файл базы данных не включён в репозиторий: он будет создан локально.

## QR-коды и просмотр с телефона

В текущей локальной конфигурации QR-коды используют `http://localhost:5173`. Они открываются на том же компьютере, где запущен frontend. Чтобы сканировать QR-код телефоном, подключите телефон и компьютер к одной Wi-Fi-сети, запустите frontend с сетевым доступом (`npm run dev -- --host 0.0.0.0`) и замените `localhost` в `backend/app/main.py` на локальный IP компьютера. Затем перезапустите backend.

## Остановка

В каждом окне терминала нажмите `Ctrl + C`.
